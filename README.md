# Jellyfin.Plugin.TmdbMultiLanguage

Experimental Jellyfin 12.1 port of TMDB Multi-Language Images.

Initial scope:
- Jellyfin 12.1 / .NET 10
- Movies and Series
- Poster, backdrop and logo images
- Per-image-type language priority such as `de,en,null`
- Personal TMDB API key

This repository starts as a compatibility port of the ideas in Iceshadow1404/TmdbMultiLanguage. The first milestone is a clean Jellyfin 12.1 build; API compatibility issues found by CI will be fixed before a release is published.
